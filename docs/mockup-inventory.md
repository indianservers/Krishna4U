## Shared visual checklist

- Edge-to-edge midnight/indigo foundation with controlled gold and cyan highlights.
- Sacred serif hierarchy for headings; readable sans serif for controls/body.
- Individual transparent artwork stays aspect-fit and uncropped.
- Glass surfaces use subtle gradient, 1 dp gold/cyan outline, restrained glow.
- Minimum 48 dp controls, native text, correct system insets and scrolling.
- Custom bottom navigation appears only on primary content destinations.
